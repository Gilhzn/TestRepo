What makes Mosaic different

∥

Mathematically clean parallel merges

Patches are commutative line-graph ops. Two changes that touch disjoint regions merge identically in any order. The repo is provably never wedged — leftover conflicts surface as structured data, not <<< markers.

∞

Real-time co-editing

yrs-backed CRDT working copy. Two peers — humans, agents, or a mix — edit the same file simultaneously and converge byte-identical. WebSocket relay + WebRTC signaling included.

⌥

Agent identity that's actually verifiable

Sigstore-style attestation chain: a human's long-term ed25519 key signs an attestation pinning an agent's session key to its claimed identity + validity window. The server enforces it on every push.

⌘

Semantic merge with renames

tree-sitter understands Rust, Python, TypeScript. Mosaic recognizes when one branch renamed a function and another edited its body — and propagates the rename. mos merge --explain prints the reasoning in plain English.

⊞

Multi-language SDK

Rust (mosaic-sdk), TypeScript (mosaic-sdk-ts), and Python (mosaic-sdk-py) — same wire protocol, same identity model. Use Mosaic from any AI agent framework.

⎙

Virtual filesystem

Mount any branch as a read-only filesystem with FUSE. ls, cat, ripgrep, your editor — they all just work against any historical state.

From zero to first commit in 5 minutes

# 1. Create a repo and identity
mos init
mos id setup --email you@your-company.com

# 2. Work like in Git
echo "hello" > greet.txt
mos add .
mos status
mos commit -i "first change"

# 3. Open a sync server (on a shared box)
mosaic-serve --repo /var/repos/team --bind 0.0.0.0:7700

# 4. From any teammate's machine
mos remote add origin http://server:7700
mos trust me                         # share my pubkey with the admin
mos push origin
mos pull origin

# 5. Browse history in any tool
mosaic-mount --repo . --branch main /mnt/preview
grep -r "TODO" /mnt/preview

# 6. AI agents use the SDK
pip install mosaic-sdk
python -c "from mosaic import MosaicClient; print(MosaicClient('http://server:7700').health())"
